## API implementada (browser e Node)

Importar de `./src/physics/contacts.mjs` (ajustar caminho relativo em main):

- `createCollisionWorld({ colliders = [], bounds = null, groundY = 0 })`: compila descritores e ordena por id; não importa Three/DOM. Bounds confirmado por Environment `{x:0,z:0,radius:55}`, groundY=0. O plano visual 140x140 não define área jogável.
- `moveActor(world, body, displacement, options?)`: `body={id,x,z,radius,height?,y?}`, `displacement={x,z}` em metros, retorna nova posição `{x,y,z,displacement,contacts,blocked,unresolved}`. Não altera entradas. Sweep contínuo, slide e correção de overlap inicial; chamar também para reposicionar spawn/respawn/reconnect com delta zero.
- `findFreePosition(world, body, {maxDistance:16, actors?})`: busca explícita e limitada para spawn/teleporte/reconnect; retorna `{x,y,z,found,relocated,distance,attempts}`. Verificar `found` antes de aceitar spawn, resetar sampler quando relocado. Resolve também o caso real de boss radius1.72 entre props onde correção local retorna `unresolved`. Nunca usar busca de posição na caminhada/dash ou atração.
- `stepActor(world, body, velocity, dt, options?)`: velocidade m/s; limita delta e subpassos; retorna campos de moveActor mais `{dt,discardedDt,substeps,velocity}`. Defaults: dt máximo .1s, subpasso 1/60s, máximo 8. `velocity` mede deslocamento pós-colisão pelo tempo aceito, excluindo `recovery` de spawn/overlap para não inventar passada. `displacement` inclui todo reposicionamento.
- `sweepStatic(world, from, to, radius=0, options?)`: contato mais próximo `{t,x,y,z,normal:{x,z},colliderId}` ou `null`; `kind:'projectile'` default, usa altura de `from.y/to.y` se fornecida. Comparar `t` com contatos de alvos; obstáculo vence empate e bloqueia mesmo projétil perfurante.
- `separateActors(world, bodies, options?)`: contatos dinâmicos determinísticos; ids únicos, `inverseMass=0` fixa posição (jogador autoritativo), >0 reparte correção. Retorna `{bodies,iterations,maxPenetration,unresolved}` na ordem original, sem mutar entradas. Correções também varrem cenário, para horda não empurrar ator através de parede. Default 4 iterações, correção por par .2m, orçamento por corpo/passo .5m, tolerância .001m. IDs estáveis obrigatórios. Chamar após movimento individual varrido; não somar solver antigo. Corpos imobilizados em geometria inválida permanecem sinalizados em `unresolved`.
